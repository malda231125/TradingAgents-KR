# Credits

TradingAgents Korea is based on the upstream TradingAgents project.

## Upstream

- Project: TradingAgents
- Repository: https://github.com/TauricResearch/TradingAgents
- Description: Multi-Agent LLM Financial Trading Framework

## Korea-market adaptation

This fork adds Korea-focused data-source integration and workflow changes, including:

- KIS-oriented structured market data
- DART disclosure/event context
- ECOS macro context
- Naver News API integration
- Korean ticker/company normalization
- Korean-language report workflow
- Codex CLI execution support
- OpenClaw skill and Notion export workflow

## Data providers

This repository can integrate with external APIs such as KIS, DART, ECOS, Naver News, FRED, SEC EDGAR, and yfinance. Each provider has its own terms of use. Users are responsible for obtaining and using credentials appropriately.
