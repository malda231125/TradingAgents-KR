# 📡 데이터 소스

[English](data-sources.md) · 한국어

TradingAgents Korea는 데이터의 의미에 따라 서로 다른 소스를 사용합니다. 한국 주식 분석에서는 국내 소스를 외국 소스로 조용히 바꾸면 해석이 달라질 수 있기 때문입니다.

## 소스 맵

| 구분 | 주요 소스 | 용도 |
|---|---|---|
| 시장 가격 / OHLCV | KIS | 국내 주식 가격·거래량 데이터 |
| 기술지표 | KIS | 한국 시장 기준 지표 |
| 재무 / 기초 데이터 | KIS | 구조화된 재무·시장 데이터 |
| 공시 / 이벤트 | DART | 기업 공시와 이벤트 신호 |
| 한국 매크로 | ECOS | 한국은행 경제통계 기반 매크로 맥락 |
| 국내 뉴스 | Naver News API | 한국어 시장·기업 뉴스 |
| 보조 외부 뉴스 | yfinance | 외부/글로벌 관점 보강 |

## 왜 하나의 universal fallback을 쓰지 않나요?

KIS 가격 응답이 없는 상황과 yfinance 응답은 항상 같은 의미가 아닙니다. 조용한 fallback은 리포트를 그럴듯하게 보이게 만들 수 있지만, 실제로는 서로 다른 데이터 정의를 섞을 위험이 있습니다.

선호하는 동작은 다음과 같습니다.

- 구조화 시장 데이터: 설정된 primary source를 사용하고, 실패 시 명확히 표시
- 뉴스: 여러 매체 관점을 합치는 것이 목적이므로 다중 소스 merge 허용
- 매크로/공시: 소스별 맥락을 명시적으로 유지

## 필요한 credential

- KIS: 시장/재무 데이터
- Naver: 국내 뉴스
- DART: 공시
- ECOS: 매크로

자세한 설정은 [설정 가이드](configuration.ko.md)를 참고하세요.

## 공개 예시 원칙

공개 샘플 리포트는 데이터 소스 범주를 언급할 수 있지만, private credential이나 raw API response를 포함하면 안 됩니다.
