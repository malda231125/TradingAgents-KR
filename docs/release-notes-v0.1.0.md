# 🚀 v0.1.0 — Korean equities multi-agent research workflow

English · [한국어](release-notes-v0.1.0.ko.md)

This is the proposed first public release note for TradingAgents Korea.

## Highlights

- Korean-equities focused TradingAgents workflow
- KIS-oriented structured market data path
- DART disclosure/event context
- ECOS Korea macro context
- Naver News + yfinance supplemental news flow
- Korean ticker/company resolver
- Codex CLI execution support
- OpenClaw helper skill for long-running formal reports
- Optional Notion export workflow
- Public release documentation and security checklist

## Intended users

- Developers experimenting with LLM-based financial research agents
- Korean-market researchers who need DART / KIS / ECOS context
- Builders who want a starting point for Korean equity research automation

## Not financial advice

Generated reports are for research and education only. They are not investment advice, trading signals, or guarantees of future performance.

## Known limitations

- Requires external API credentials for the intended full workflow
- Data-provider terms and limits must be respected by users
- Report quality depends on local LLM/CLI setup and available data
- Backtesting / evaluation harness is still a roadmap item
